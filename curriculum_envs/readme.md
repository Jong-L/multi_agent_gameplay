# 课程学习阶段设计

> 训练范式：单智能体 PPO 技能习得 → 多智能体 IPPO + PFSP 对手池迭代博弈

---

## Phase 1: 单智能体技能课程

核心原则：**每个阶段只引入一个新元素**，让智能体专注掌握一项新技能，而非同时应对多个挑战。

| 阶段 | 环境元素 | 习得技能 | 设计意图 |
|:---:|----------|----------|----------|
| s1 | 奖励球 | 追球 | 建立最基本的"球=正奖励"认知，学会趋近目标 |
| s2 | 奖励球 + 障碍物 | 避障追球 | 在 s1 追球本能上叠加路径规划，学会绕过障碍物到达目标 |
| s3 | 奖励球 + 敌人 | 战斗 + 经济管理 | 在 s2 追球基础上引入战斗；**移除障碍物**让智能体专注学习战斗和资源管理 |
| s4 | 奖励球 + 障碍物 + 敌人 | 综合技能整合 | 将追球、避障、战斗三项技能整合到同一环境中；智能体已分别掌握各技能，此阶段只需要学会调度和平衡 |

### 设计说明

**s3 为什么没有障碍物？**
s2 刚学会避障追球，如果 s3 同时引入敌人 + 保留障碍物，智能体需要同时应对两个新挑战（战斗 + 在复杂地形中战斗）。移除障碍物让 s3 聚焦战斗基础——攻击时机、血量管理、何时追球何时打架。障碍物在 s4 回归，此时战斗已成为本能，只需叠加导航。

**s4 是"整合"而非"新技能"**
s4 没有引入任何新元素，智能体在 s1-s3 已经见过球、墙、敌人。s4 的任务是把这些技能组合起来——在追球途中遇到敌人决定打还是绕、在有障碍物时寻找有利战斗位置。这个阶段本质上是在学习"技能调度策略"。

---

## Phase 2: 多智能体博弈

从 s4 训练出的 4 个单智能体模型出发，进入 IPPO + PFSP 对手池迭代训练：

```
s4 模型 (ppo_agent_{0..3})
    ↓
IPPO 共训 100万步 → 保存中断点 → 构建对手池
    ↓
PFSP 对手池迭代博弈 (每轮 80万步 × 3轮)，轮回训练各 agent
    ↓
最终模型评估：对手池博弈智能体 vs 纯 IPPO 智能体 → 博弈动力学分析
```

完整多智能体环境使用 `godot-game/`（奖励球 + 障碍物 + 敌人 + 对手玩家）。
