# 答辩材料：基于机器学习的对抗性机器博弈研究

## 1. Overview（概述）
- **题目**：基于机器学习的对抗性机器博弈研究
- **性质**：华北电力大学本科毕业设计论文
- **核心问题**：如何构建对抗性多智能体博弈环境，并比较不同训练范式下的策略涌现特性
- **核心命题**：对抗结构产生的动力学（策略循环、非传递性、对抗进化）是研究重心，技术手段（PBRS、IPPO、课程学习）是使能层
- **关键结论**：平均策略博弈方法取得最高均奖励（586.3），显著优于 IPPO（495.0）和对手池博弈（339.0）

## 2. Background（研究背景）
- **RL 成就**：AlphaGo、OpenAI Five 等证明了深度学习在博弈中的突破性表现
- **博弈作为试金石**：博弈是检验智能体泛化能力、战略思维、适应性学习的最佳平台
- **多智能体 = 博弈动力学问题**：多智能体强化学习天然涉及博弈论框架，需处理非平稳性、信用分配、部分可观测等核心挑战
- **现有困境**：传统 MARL 算法在多智能体自由对抗场景中表现不稳定，策略易陷入循环或退化
- **本文切入点**：通过构建可控博弈环境 + 系统化训练范式对比，揭示多智能体对抗训练的规律

## 3. Key Info（关键信息）
### 3.1 环境设计
- **游戏名称**：Tiny Swords
- **类型**：2D 俯视角四人混战竞技场
- **引擎**：Godot 4.x
- **智能体数量**：4（战士/刺客/骑士/游侠），从地图四角出生
- **动作空间**：6 个离散动作（上/下/左/右/无操作/攻击），朝向由最近移动方向决定
- **观测空间**：174 维分段式观测（SELF/PLAYER/BALL/ENEMY/MAP 五段）
- **得分来源**：攻击/击杀玩家、击杀野怪、拾取奖励球；被攻击/死亡扣分；饥饿机制不进食扣分

### 3.2 角色差异化设计
- **战士**：均衡型（攻击力/移速/血量平衡）
- **刺客**：高速高攻脆皮（高风险高回报）
- **骑士**：高坦度长臂（持续作战能力强）
- **游侠**：最远射程（安全输出位置）
- **设计原则**：属性零和约束，形成石头剪刀布式非传递博弈

### 3.3 算法方法
- **奖励塑形**：基于势能的奖励塑形（PBRS），缓解多智能体稀疏奖励问题
- **课程学习**：三阶段课程（S1 仅吃球 → S4 完整战斗），逐步增加环境复杂度
- **网络架构**：GRU-MLP 时序网络（处理部分可观测 POMDP），对比 MLP / Segmented MLP
- **三种训练范式**：
  - IPPO（独立 PPO，分布式训练分布式执行 DTDE）
  - PFSP 对手池（训练时采样不同历史策略作为对手）
  - 平均策略博弈（固定对手为所有历史策略的平均）

### 3.4 实验设置
- **训练总步数**：800 万步（统一评估基准）
- **评估方法**：20 组对手池测试，Bootstrap 95% 置信区间，配对 t 检验，Cohen's d 效应量
- **统计结果**：Average(583.9) > IPPO(538.2) > Pool(318.1)，三项两两 p<0.01

## 4. Evidence（证据与数据）
### 4.1 单智能体实验
- Phase 1 课程学习验证了从简单到复杂的学习曲线有效性
- GRU-MLP 在时序任务中优于 MLP，验证了记忆机制对部分可观测的价值

### 4.2 多智能体对比实验
- **均奖励排名**：Average(586.3) > IPPO(495.0) > Pool(339.0)
- **统计显著性**：三项两两比较均 p<0.01，效应量 Cohen's d 中等至大
- **PFSP 表现分析**：Pool 方法表现差劲，归因于训练曲线高波动性 + 策略循环不稳定

### 4.3 核心研究发现
- 策略间存在明显的非传递性竞争关系（类似石头剪刀布）
- 平均策略通过平滑历史策略分布，提供更稳定的训练信号
- PFSP 的 ε-greedy 采样（10% 均匀采样）仍不足以保证训练稳定性

## 5. Analysis（分析）
### 5.1 核心叙事线
- **博弈动力学是中心**：策略循环、非传递性、对抗进化是本文关注的核心现象
- **技术手段是使能层**：PBRS 解决稀疏奖励、课程学习降低探索难度、GRU 处理部分可观测
- **重心不在算法优劣**：不在于证明 IPPO 比 PFSP 好，而在于揭示对抗结构中策略如何涌现

### 5.2 工程经验教训
- 环境 step() 的 info 设计至关重要，影响后续分析和调试
- 保存检查点时应同步保存 tensorboard 信息
- 游戏规则设计初期就应具备博弈性，避免后期调整

### 5.3 研究意义三层面
- **环境层面**：提供了 Tiny Swords 可控博弈实验平台，支持课程学习与多种训练范式
- **方法层面**：提出了两阶段训练范式（单智能体预训练 → 多智能体联合训练）
- **理论层面**：揭示了策略循环涌现条件、非传递博弈的动力学特征

## 6. Outlook（展望与后续）
### 6.1 未完成工作
- 联盟训练机制：因工程难度未实现
- 第五章实验结果不理想：策略循环不稳定，未达到预期收敛

### 6.2 后续方向
- 用户计划转向简单单智能体 RL 项目（马里奥/贪吃蛇），体验单智能体训练全流程
- 对多智能体博弈的深入理解将有助于后续更复杂的项目
- 环境设计和工程经验可直接复用到新项目中

## Summary
- **权威来源**：论文本身（本科毕设），实验数据完整，统计方法规范
- **知识缺口**：联盟训练机制未实现，PFSP 不稳定性的理论解释可进一步深化
- **核心价值**：提供了从零构建多智能体博弈环境、设计训练范式、进行系统化对比实验的完整案例
